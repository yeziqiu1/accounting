# 小账本 · 使用说明

一个网页版的收支记账工具：支出/收入分开记，分类能自己改，购物能写评价，有预算提醒、每日收支、语音快记，也能用苹果「快捷指令」把截图直接变成一笔账。

## 文件清单

| 文件 | 作用 |
| --- | --- |
| `index.html` | 网页本体，双击即可打开 |
| `styles.css` | 界面样式（浅色 / 深色自动适配） |
| `app.js` | 全部功能逻辑 |
| `sw.js` | 离线缓存（部署到网上后生效） |
| `manifest.json` / `icon.svg` | 添加到手机主屏时的图标与名称 |

## 怎么打开

1. **电脑上直接用**：双击 `index.html` 就能用，数据保存在这个浏览器的本地存储里。
2. **手机上用（推荐）**：把这个文件夹传到任意静态托管（例如 GitHub Pages、Vercel、Netlify，拖拽上传即可），得到 `https://…/index.html`。
   在 iPhone 上用 Safari 打开，点「分享 → 添加到主屏幕」，之后像 App 一样全屏使用，断网也能记账。
3. **要接快捷指令，必须用第 2 种方式**：快捷指令只能打开网址，打不开本机文件。

## 功能一览

- **支出 / 收入**：顶部切换，账单分开统计。
- **分类与子分类**：餐饮、购物、服饰、日用、数码、美妆、交通、居住、通讯、娱乐、医疗、教育、人情、宠物、运动、其他……每个分类都能改名字、换图标、换颜色，也能随时添加子分类（例如「餐饮 → 咖啡奶茶」）。记子分类时，统计会自动合并到一级分类。
- **购物评价**：每笔支出都能标记 ⭐️ 推荐 / 👍 好 / 😐 一般 / 👎 不好，并写下理由。概览页会汇总最近的评价，下次买东西前翻一翻就知道值不值。
- **预算**：设置月度总预算，再给常超支的分类单独限额；会显示已用百分比、剩余额度、平均每天还能花多少，超支变红提醒。
- **每日收支**：概览页有近 14 天每日支出柱状图（当天有收入会标一个小绿点）；明细页按天分组，每天都能看到当天的支出与收入合计。
- **语音快记**：说一句「午餐 32 元 食堂，味道一般」，自动识别金额、名称、分类、日期和评价。识别不准的可以直接改，也能用打字的方式解析。
- **数据备份**：导出 JSON 备份、导出 CSV 表格（可用 Excel / 数字打开），换设备时导入即可。

## 苹果「快捷指令」怎么设

前置条件：把网页部署到网上，拿到一个网址，例如 `https://example.com/index.html`。

1. 打开「快捷指令」App → 右上角新建 → 名字叫「记一笔」。
2. 第一步：添加动作「从图像中提取文本」（iOS 18 及以上），选择要处理的截图；也可以先用「获取最新的照片」再提取文本。
3. 第二步：添加「文本」动作，把网址和识别到的文字拼在一起：

   ```
   https://example.com/index.html?text=识别到的文本
   ```

   这会把整段文字交给小账本自己解析（金额、商家、日期、评价都能认）。
4. 第三步：添加「打开 URL」动作，URL 选上一步的文本。
5. **想每次核对一下**：网址里保留 `save=0`，会弹出已经填好的记账表单，确认后保存。
   **想一句话直接入账**：把参数换成 `save=1`，打开就直接记好，不弹表单。
6. 想让识别更准，可以用「匹配文本」先取出金额和商家，再分开传参：

   ```
   https://example.com/index.html?amount=32.5&title=星巴克拿铁&category=咖啡奶茶&date=2026-09-17&type=expense&rating=good&reason=好喝&save=1
   ```

7. 最后在指令详情里打开「在共享表单中显示」或绑定到「轻点背面」，付款截图一到手就能一键入账。

### 支持的参数

| 参数 | 说明 |
| --- | --- |
| `amount` | 金额，必填（例如 `32.5`） |
| `title` | 货物 / 商家名称 |
| `category` | 分类或子分类名，例如 `餐饮`、`咖啡奶茶` |
| `date` / `time` | `2026-09-17` / `13:20`，不填默认当前时间 |
| `type` | `expense`（支出，默认）或 `income`（收入） |
| `rating` | `recommend` / `good` / `ok` / `bad`（也可以用中文：推荐、好、一般、不好） |
| `reason` / `note` | 评价理由 / 备注 |
| `text` | 一句话文本，交给小账本自动解析 |
| `save` | `1` 直接保存，`0` 打开表单确认 |

小账本「更多」页里也能生成一条示例链接、复制按钮，以及「在本机试一下」。

## 数据说明

- 所有记录只保存在你自己的浏览器里，不会上传到任何服务器。
- 换手机 / 换浏览器前，先在「更多 → 导出备份」存一份 JSON；在新设备上「导入备份」即可。
- 「清空记录」只删记录，分类和预算会保留。
